# Lila Magic Sword Escape

Roblox Studio + Rojo prototype for a school-themed cooperative magic sword escape game.

## Status
- Four-floor **fictional blockout** generated at runtime by `src/server/SchoolBuilder.server.luau`.
- Eight sword definitions in `src/shared/SwordConfig.luau`.
- **Not yet implemented:** sword abilities, puzzles, bosses, functional stairways, accurate real-school layout.
- The current building is **not** a verified reconstruction of Lila Art High School.

## Setup
1. Install Roblox Studio, Rojo CLI and Rojo Studio plugin.
2. Clone this repository.
3. In its directory, run `rojo serve`.
4. Open a new Baseplate in Roblox Studio and connect via the Rojo plugin.
5. Press Play to generate the blockout.
